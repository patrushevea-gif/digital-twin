# Checklist данных для перехода от demo к реальной модели

## Планировка

- схема цеха;
- габариты оборудования;
- расположение складов, лаборатории, фасовки;
- маршруты движения материала;
- точки отбора проб.

## Оборудование

- производитель и модель;
- паспортная производительность;
- установленная мощность;
- диапазоны рабочих параметров;
- ограничения и аварийные условия;
- регламент обслуживания.

## Производство

- типовые партии;
- реальные длительности операций;
- переналадки между цветами и типами продукта;
- очистки;
- причины простоев;
- очереди и ожидания;
- фактический выпуск по сменам.

## Качество

- параметры гранулометрии;
- цветовые допуски;
- gel time;
- блеск;
- доля oversize;
- протоколы ОТК;
- причины брака.

## Энергия

- мощность и фактическое потребление экструдера;
- мощность мельницы;
- аспирация;
- компрессорный воздух;
- сменные профили нагрузки.

## Будущая телеметрия

- PLC/SCADA теги;
- частота обновления;
- единицы измерения;
- правила нормализации;
- качество сигнала;
- связь тега с оборудованием.
