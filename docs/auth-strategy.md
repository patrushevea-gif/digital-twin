# Минимальная авторизация PowderTwin

## Что сделано сейчас

В MVP добавлен простой код доступа на входе в интерфейс:

- код: `twin2026`;
- после входа доступ запоминается в браузере;
- кнопка `Выход` сбрасывает доступ на текущем устройстве;
- нет личных кабинетов, регистрации и входа через аккаунт Vercel.

Это удобно для личного прототипа и демонстраций, но не является промышленной защитой: код находится во фронтенде и может быть найден в исходном HTML.

## Как лучше защищать дальше

1. **Vercel Password Protection**
   - Самый простой вариант на Vercel.
   - Посетитель вводит пароль, без входа в твой Vercel-аккаунт.
   - Хорошо подходит для закрытого демо и MVP.

2. **Vercel Routing Middleware**
   - Серверная проверка до отдачи страницы.
   - Можно сделать Basic Auth или cookie-сессию.
   - Пароль хранится в Vercel Environment Variables, а не в HTML.

3. **Supabase / Clerk / Auth.js**
   - Нужны, когда появятся роли, пользователи, история действий, разные права доступа.
   - Для текущего этапа избыточно.

## Рекомендация

Пока оставить текущий код доступа. Когда начнем хранить реальные заводские данные в базе, перейти на Vercel Password Protection или Routing Middleware с паролем в переменных окружения.
