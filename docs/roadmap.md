# Roadmap

## Этап 0. Product seed

- Рабочая demo-панель.
- Seed-модель линии.
- Документация архитектуры.
- JSON Schema для модели.
- Базовая проверка JavaScript.

## Этап 1. Offline operational twin

- Backend API.
- База данных PostgreSQL.
- CRUD справочников оборудования, рецептур и маршрутов.
- Редактор сценариев смены.
- Расчет OEE, bottleneck, качества и энергии на сохраненных сценариях.

## Этап 2. Simulation twin

- Дискретно-событийная симуляция партий.
- Очереди между узлами.
- Переналадки и очистки.
- Генерация сменного плана.
- Сравнение сценариев.

## Этап 3. Spatial twin

- 2D-планировка по реальным координатам.
- 3D-визуализация цеха.
- Связка объектов 3D с паспортами оборудования.
- Тепловая карта загрузки и риска.

## Этап 4. Connected twin

- OPC UA connector.
- MQTT/Sparkplug connector.
- MES/ERP exchange.
- Хранилище временных рядов.
- Онлайн-события и алерты.

## Этап 5. AI-assisted twin

- Объяснение причин простоев.
- Подбор сценариев производства.
- Рекомендации по переналадкам.
- Поиск аномалий.
- Автоматические сменные отчеты.
