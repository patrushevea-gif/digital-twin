# PowderTwin: цифровой двойник линии порошковой краски

Основа проекта для цифрового двойника завода, начиная с линии производства порошковой краски. Сейчас репозиторий не требует данных с оборудования: он содержит демонстрационную модель, интерактивный прототип и инженерные документы, чтобы дальше постепенно заменить допущения реальными паспортами, маршрутами, рецептами и телеметрией.

## Что уже заложено

- интерактивная демо-панель линии без внешних зависимостей;
- стартовая asset-модель: зоны, оборудование, параметры, рецептуры, сценарии;
- симуляция загрузки, bottleneck, OEE, качества и энергии;
- визуальный слой с анимированным потоком материала;
- JSON Schema для будущего API и базы данных;
- дорожная карта от offline-модели к подключению OPC UA / MQTT / MES;
- checklist данных, которые нужно собрать на заводе.

## Быстрый запуск

```powershell
npm run dev
```

Откройте `http://localhost:5173`.

Если npm не нужен, можно запустить напрямую:

```powershell
python -m http.server 5173 --directory apps/web
```

## Принцип проекта

Центр системы - не 3D-картинка, а цифровая модель активов, партий, рецептур, событий и ограничений. Визуализация подключается к этой модели как один из интерфейсов. Такой подход позволит сначала работать offline, а позже добавить реальные сигналы с PLC, SCADA, MES или лаборатории без полной переделки.
